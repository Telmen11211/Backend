# Лекц 4-ийн 8 асуултын хариу

1. POST шинэ нөөц үүсгэнэ, PATCH байгаа нөөцийн зарим талбарыг засна. Энэ API амжилттай нэмэхэд 201, засахад 200 буцаана.
2. /books/:id замын id шаардлагатай. req.query дахь хайлтын q нь энэ API-д сонголттой.
3. express.json() route-ийн дараа байвал JSON унших үед req.body задлагдаагүй байна. Parser-ийг route-уудаас өмнө бүртгэнэ.
4. Middleware хариу илгээхгүй, next() дуудахгүй бол хүсэлт цааш дамжихгүй, клиент хүлээнэ.
5. find эхний тохирох элементийг, олдохгүй бол undefined буцаана. filter тохирсон бүх элементийн массив, олдохгүй бол хоосон массив буцаана.
6. Ном олдохгүй болон route олдохгүй үед хоёул 404. Хариуны message нь шалтгааныг ялгана.
7. Асинхрон функцийн await-ийг мартвал Promise авна. Үр дүнгийн title зэрэг талбарыг шууд уншихад undefined байж болно.
8. Express алдааг дараа байрлах error handler руу дамжуулдаг тул бүх route-ийн дараа бүртгэнэ. Error handler (err, req, res, next) гэсэн дөрвөн параметртэй.
