# Семинар 6

Author болон Book холбоос, seed, relation query.

## Ажиллуулах

```bash
npm ci
cp .env.example .env
# .env дотор өөрийн PostgreSQL холболтыг тохируулна.
# library_seminar_6 нэртэй хоосон database үүсгэнэ.
npm run db:generate
npm run db:migrate
npm run db:seed
npm run dev
```

http://localhost:3000 хаягаар шалгана. Нэг удаад нэг семинарын сервер ажиллуулна.

Өгөгдөл PostgreSQL-д хадгалагдана.
